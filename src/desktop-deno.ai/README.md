# NavPlace Deno Desktop

This is a Deno Desktop port of the Electron app in `src/desktop-electron`.
It was fully generated by AI (GPT 5.5).
The Electron version is the only source of truth; this Deno version should be updated from it, not the other way around.

It keeps the existing desktop behavior:

- Reads settings from `~/.navplace/settings.yaml`.
- Reads local collections from `~/.navplace/README.md` when no remote collection is configured.
- Loads the existing `designs/<name>/index.html` files.
- Exposes the same `window.ElectronApp` renderer API used by `lib/navplace.js`.
- Opens bookmark URLs in the system browser.
- Keeps a single running instance on Unix-like systems with the same socket path as the Electron app.

## Requirements

Deno 2.9 or newer is required for `deno desktop`.

If `deno task desktop` reports `Module not found ".../desktop"`, your local Deno binary is too old and is treating `desktop` as a script path. Upgrade Deno first:

```bash
deno upgrade
```

## Settings

Copy `config/settings.example.yaml` to `~/.navplace/settings.yaml`:

```yaml
personal_access_token:
collection_url:
events_url:
```

Leave values empty to use the local `~/.navplace/README.md` collection.

## Development

```bash
cd src/desktop-deno.ai
deno task start
```

This starts the local HTTP app. Open the printed URL in a browser if you are not running through `deno desktop`.

## Desktop Build

```bash
cd src/desktop-deno.ai
deno task desktop
```

Desktop artifacts are written under `build/`.

For hot reload while working on the desktop shell:

```bash
deno task desktop:hmr
```

The build task includes `../../designs` and `../../lib` because the Deno app serves the existing static UI files directly.
